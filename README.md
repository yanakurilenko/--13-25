# Инструмент визуализации графа зависимостей
## Вариант 13 (Ubuntu apt, DFS с рекурсией, Graphviz)

## Общее описание
CLI-приложение для анализа и визуализации
графа зависимостей пакетов Ubuntu (apt).
Получение зависимостей без использования
готовых менеджеров пакетов.

## Настраиваемые параметры
- `--package` (`-p`): имя пакета (обязательно)
- `--repo` (`-r`): URL репозитория или путь
  к файлу тестового репозитория (обязательно)
- `--version` (`-v`): версия пакета
  (по умолчанию 'latest')
- `--test-mode`: режим работы с тестовым
  репозиторием
- `--ascii-tree`: вывод в формате ASCII-дерева

## Команды для запуска
```bash
python src/main.py -p nginx -r \
  https://packages.ubuntu.com -v 1.0.0
